BeFree INC website logo kit

LOGO
- logo/befree-logo-master.png: transparent master image
- logo/befree-logo-*.png: responsive PNG exports
- logo/befree-logo.svg: SVG container with embedded transparent PNG

FAVICON / APP ICON
- favicon/favicon.ico: multi-resolution browser icon
- favicon/favicon.svg and favicon-*.png: web icons
- favicon/apple-touch-icon.png: Apple touch icon (180x180)
- favicon/android-chrome-192x192.png and android-chrome-512x512.png

HTML head example:
<link rel="icon" href="/favicon/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="/favicon/favicon.svg">
<link rel="apple-touch-icon" href="/favicon/apple-touch-icon.png">

Note: SVG files are scalable containers that embed the transparent PNG artwork.
They are not path-based editable vector artwork. A true vector redraw would be
needed for infinitely scalable, individually editable shapes and typography.
All artwork uses transparency; the maple leaf has been changed to Canadian red.
